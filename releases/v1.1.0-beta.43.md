MF-Design Center 1.1.0-beta.43 · Windows x64 测试版

本次更新
- 新增主题风格入口，提供薄荷清透、珠光漫彩、轻盈橙白、晶透琉璃四个预设，以及一个自定义。
- 新风格可开启或关闭，关闭后恢复原来的皮肤和配色。
- 自定义默认薄荷绿＋柔雾粉，可调整两种颜色、渐变方向、透明度与模糊程度。
- 每套参数独立保存；选择和调节即时预览，点击应用保存，重启后保留，支持完整 ZIP 备份。
- 新主题隐藏顶部旧装饰文案，保留窗口拖动和关闭功能。
- 新手指南加入实际主题截图和切换演示。

使用方法
安装后点击左下角“主题风格”，开启开关，再选择预设或自定义并应用。首次升级保持原皮肤，不强制启用。

下载与更新
- Windows x64 安装版请选择 MF-Design-Center-1.1.0-beta.43-win-x64.exe。
- Windows ZIP 版需完整解压后运行 MF-Design Center.exe。
- beta.41 及以上开启“接收测试版更新”后，可在软件内检查本次更新。
- beta.40 及以前需手动安装本版一次。下载后仍需退出旧版并手动运行安装程序。
- SHA256SUMS.txt 用于校验附件；GitHub 自动生成的 Source code 压缩包不是安装包。
- macOS 安装包后续提供。

升级前建议导出完整资料备份，从托盘退出旧版，再运行安装程序。原资料目录和应用 ID 保持不变。安装包未配置代码签名，Windows 可能提示未知发布者。
