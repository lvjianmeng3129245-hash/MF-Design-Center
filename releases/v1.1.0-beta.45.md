MF-Design Center 1.1.0-beta.45 · Windows x64 测试版

本次更新
- 修复主题风格与外观入口同时高亮，增加按钮间距，切换其他页面自动收起主题面板并撤销未应用的预览。
- 点选风格或自定义背景立即开启预览，点击“应用主题”后保存。
- 主题启用时，主题配色和材质优先于原外观；关闭主题后恢复原外观设置。
- 主界面和收藏小窗口同步预览、应用和撤销，隐藏后重新打开也保持同步。
- 包含 beta.44 的自定义图片背景：填充、适应、拉伸、平铺、居中，以及独立透明度和模糊设置。
- 收藏小窗口品牌采用 MF / Design Center 双排布局，品牌靠左、窗口操作靠右；原皮肤标题栏与内容背景连贯。
- 图文指南同步更新，保留薄荷清透、珠光漫彩、轻盈橙白、晶透琉璃与自定义主题入口。

使用方法
安装后点击左下角“主题风格”，点选风格或自定义背景即可预览，点击“应用主题”保存；关闭主题可恢复原外观。建议 beta.43 用户升级至本版。

下载与升级
- Windows x64 安装版：MF-Design-Center-1.1.0-beta.45-win-x64.exe（推荐）。
- Windows ZIP：完整解压后运行 MF-Design Center.exe。
- beta.41 及以上开启“接收测试版更新”后，可在软件内检查本次更新；beta.40 及以前需先手动安装本版一次。
- 升级前导出完整备份，从托盘退出旧版，再运行安装程序。原应用 ID 与资料目录保持不变。
- 当前为浏览器下载后手动安装，不会后台静默安装或强制重启。
- SHA256SUMS.txt 用于核对附件；GitHub 自动生成的 Source code 压缩包不是软件安装包。
- 安装包未配置代码签名，Windows 可能提示未知发布者。macOS 安装包后续提供。
