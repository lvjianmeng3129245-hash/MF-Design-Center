MF-Design Center 1.1.0-beta.49 · Windows x64 测试版

本次更新
- 隐藏当前组的旧贴图后，可将新截图直接贴到桌面，旧贴图继续隐藏；新图准备期间切组时，新图跟随当前组。
- 优化 F3 本组显示/隐藏，减少重复显示窗口与界面刷新。
- 鼠标移到贴图上，按 F2 切换鼠标穿透，再按一次恢复交互；重命名改为 Shift+F2。
- 优化拖动跟随鼠标的流畅性，减少重复移动，松手时保存最终位置。
- 保留 Ctrl+滚轮透明度平滑调节及软件内下载、校验、取消、重试与重启安装。

包含 beta.48 的 ZIP 版升级能力
完整 ZIP 版放在独立程序文件夹中，也支持软件内更新。点击“重启并安装”后，会在当前文件夹覆盖升级并转为安装版，随后自动重新打开，保留原资料。直接解压到磁盘根目录、桌面根目录或程序文件不完整时，会提示先整理到独立文件夹。

更新方式
- beta.46 及以上 Windows 安装版，或 beta.48 及以上完整 ZIP 版：开启“接收测试版更新”，在“设置与备份 → 软件更新”检查更新，下载校验完成后点击“重启并安装”。
- beta.47 及以前 ZIP 版：先手动下载并完整解压 beta.49 到独立文件夹，或使用 EXE 安装版；之后可在软件内升级。
- beta.45 及以前安装版：先手动运行本版安装程序一次。
- 升级前建议导出完整备份；未保存内容可取消重启。软件沿用原应用 ID 与资料目录，不需要先卸载。
- F2、F3 如被其他软件占用，请检查快捷键设置和冲突。
