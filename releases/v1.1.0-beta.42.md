MF-Design Center 1.1.0-beta.42 · Windows x64 测试版

本次更新
- 左上角名称采用两行排版：加粗 MF，较小 Design Center。
- Logo 使用透明背景循环动画，保留流动光泽；隐藏窗口暂停，减少动态效果时显示静态图。
- 桌面便签置顶后不再占用任务栏，后台提醒与托盘入口继续保留。
- 使用指南同步更新。

在线更新
- 本版本包含 beta.41 引入的 GitHub 更新检查功能，默认指向本仓库。
- 启动后按检查间隔检查，运行期间每 6 小时检查，也可在“设置与备份 → 软件更新”手动检查。
- beta.41 用户开启“接收测试版更新”后可检测本版本；beta.40 及以前请先手动安装本版本一次。
- 更新弹窗提供版本说明、稍后提醒、跳过版本及下载安装包入口。
- 当前流程为浏览器下载后手动运行安装程序，不会后台静默安装或强制重启。

下载选择
- Windows 安装版：MF-Design-Center-1.1.0-beta.42-win-x64.exe（推荐）。
- Windows ZIP：MF-Design-Center-1.1.0-beta.42-win-x64.zip，完整解压后运行。
- SHA256SUMS.txt 用于核对以上两个文件的完整性。
- GitHub 自动生成的 Source code 压缩包仅包含发布仓库文档，不是软件安装包。
- macOS 安装包后续提供。

升级说明
安装前导出完整备份，从右下角托盘退出旧版，再运行安装程序。原应用 ID 与资料目录保持不变。当前安装包未配置代码签名，Windows 可能提示未知发布者。
