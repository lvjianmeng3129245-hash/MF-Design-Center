本次更新
- 优化桌面贴图 Ctrl+滚轮透明度调节，改为原生平滑过渡，连续输入跟随最新目标，减少逐格卡顿。

更新方式
- beta.46 Windows 安装版：在“设置与备份 → 软件更新”检查更新，开启“接收测试版更新”，点击“立即更新”；下载及校验完成后点击“重启并安装”。
- beta.45 及以前，或 ZIP 版：先手动运行本版 Windows 安装程序一次，以后即可在软件内升级。
- 安装前建议导出完整备份。自动升级不会提前卸载，继续使用原应用 ID 与资料目录；有未保存内容可以取消重启。
