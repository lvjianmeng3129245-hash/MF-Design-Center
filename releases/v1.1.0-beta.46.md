MF-Design Center 1.1.0-beta.46 · Windows 安装版软件内更新

本次更新
- Windows 安装版支持在软件内下载更新，显示进度、取消下载和失败重试。
- 下载完成并校验通过后显示“重启并安装”。点击后正常退出，自动覆盖升级并重新打开。
- 有未保存内容可取消退出，更新包保留；录制、备份或恢复进行中会先提示完成当前工作。
- 不需要先卸载。继续使用原应用 ID 和 MF Design 资料目录，保留收藏、便签、导图和设置。
- 修复并发检查可能把正在下载的版本替换为另一版本的问题。
- 保留 beta.45 的主题优先级、自定义图片背景、小窗口同步与界面修复。

首次使用
beta.45 及以前必须先手动安装本版一次。以后可在软件内完成下载与重启安装。
ZIP 版需要先运行 Windows 安装程序，才能启用自动覆盖升级。
当前为测试版，需要开启“接收测试版更新”。建议首次升级前导出完整资料备份。

下载说明
Windows 用户请选择 EXE 安装程序。ZIP 版需完整解压后运行；GitHub 自动生成的 Source code 压缩包不是软件安装包。macOS 安装包后续提供。
