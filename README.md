# MF-Design Center

面向设计工作的桌面效率工具：提示词管理、截图与贴图、思维导图、桌面便签与提醒。

本仓库用于分发安装包、记录版本变化和提供在线更新信息。软件源码及个人资料不在本仓库公开。

## 主题与背景

安装后点击左下角“主题风格”，点选 **薄荷清透、珠光漫彩、轻盈橙白、晶透琉璃或自定义** 即可预览，点击“应用主题”保存。自定义支持两种颜色和渐变方向，也可使用本地图片背景，选择填充、适应、拉伸、平铺或居中，并调节透明度与模糊程度。

主题启用后配色和材质优先于原外观，关闭主题恢复原外观。已修复主题与外观入口同时高亮、按钮拥挤等问题；主窗口与收藏小窗口同步预览和保存，切换页面撤销未应用的预览。beta.46 保留这些修复，软件内图文指南已更新。

## 主要功能

- **提示词资料库**：分组、标签、搜索、复制、收藏与备份。
- **截图与贴图**：区域截图、长截图、标注、独立贴图及区域录制。
- **思维导图**：独立导图管理、布局、编辑及导出。
- **桌面便签**：多张便签、待办、提醒与置顶。
- **软件内更新**：检查新版本，在软件内下载并校验，由用户点击重启安装。

日常资料保存在本机；检查更新需要联网。更新检测不需要 GitHub 账号或 API Key。

## 安装与升级

1. 首次使用 Windows 安装程序，按安装向导完成安装；ZIP 版需要完整解压后运行 `MF-Design Center.exe`。
2. 升级前在“设置与备份”导出完整备份。
3. 从系统托盘退出旧版，再运行新安装程序。软件沿用原有应用 ID 和 `%APPDATA%\MF Design` 资料目录。
4. 不要在升级过程中删除旧资料目录。

当前安装包未配置代码签名，Windows 可能显示未知发布者提示。可先使用下列命令核对文件哈希，再自行决定是否安装：

```powershell
Get-FileHash .\MF-Design-Center-1.1.0-beta.46-win-x64.exe -Algorithm SHA256
```

## 在线更新怎么使用

**beta.45 及更早版本需要先手动安装 beta.46 一次。** beta.41–45 的更新按钮仍通过浏览器下载，这是旧版自身的行为。

- 默认在启动约 25 秒后尝试检查；距离上次检查不足 6 小时会跳过当次启动检查，运行期间每 6 小时检查一次。
- 可在“设置与备份 → 软件更新”手动点击“检查更新”。
- 更新来源：`https://github.com/lvjianmeng3129245-hash/MF-Design-Center`。
- 当前发布的是测试版，请开启“接收测试版更新”。关闭后仅接收正式版。
- 安装版发现更高版本后显示更新说明，点击“立即更新”在软件内下载，支持取消和失败重试。
- 校验完成后点击“重启并安装”，自动覆盖升级并重新打开；可以选择“稍后安装”。普通退出不会自动安装。
- 有未保存内容可取消重启；录制、备份或恢复进行中需先完成当前工作。建议提前导出完整备份。
- ZIP 版仍提供浏览器下载安装入口，请运行安装程序以启用软件内升级。
- 软件完全退出或无法连接 GitHub 时不能检查更新；网络失败可稍后手动重试。
